I work where biotechnology, data and code overlap. My research is in bioprocess engineering, and most of the software I write exists because a lab problem needed solving faster than a spreadsheet could solve it: kinetic simulators, calibration and validation workflows, bioinformatics pipelines, instrument automation. When I am not in the lab, I build games in Unity.

### 🔬 What I'm doing

- **PhD candidate in Bioengineering**, İstanbul Medeniyet University, working on anaerobic digestion, membrane processes and micropollutant removal.
- **Senior Engineer** at Micrho Biyoteknoloji, running the experimental and computational side of a fermentation derived biogas additive R&D project.
- **Currently building:** multi agent orchestration systems, and simulation tools that non specialists can actually use.
- **Currently learning:** applied AI systems, advanced Unity techniques.

### 🧪 Selected work

| Project | What it does |
| --- | --- |
| **AM2 Digestion Simulator** | Self contained HTML tool for anaerobic digestion modelling: RK4 ODE solver, live Chart.js plots, parameter sliders and a random search optimizer. |
| **Primer Design Pipeline** | qPCR primer design and in silico validation for species specific microbial monitoring, built on Biopython, primer3, BLAST+ and MFEprimer. |
| **Academic Paper Fetcher** | Metadata and full text retrieval across Unpaywall, OpenAlex, Semantic Scholar and Europe PMC. |
| **G-code Automation Suite** | Python toolchain for 3D printing with multi threaded temperature monitoring. |
| **P2P Communication App** | Peer to peer audio, video and data channels over WebRTC and PeerJS. |
